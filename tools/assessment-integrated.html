저장 상태 확인 중

성적 파일 추가하기

정기시험 일람표(PDF)와 수행평가 파일일괄등록(XLSX)을 함께 또는 반복 등록하세요.
인터넷 연결 없이 처리 · 파일은 외부로 전송되지 않습니다.
사용 안내

정기시험 교과목별 일람표(PDF)와 수행평가 파일일괄등록(.xlsx)을 지원합니다. 기존 수행평가 일람표 PDF도 호환됩니다. 엑셀의 학년도·학기·학년은 파일명에서 인식하며, 정보가 없으면 직접 확인·입력합니다. 파일명에 적힌 강의실 대신 실제 반 열을 사용합니다. 빈 점수는 결시나 0점으로 추정하지 않습니다. 학년도·학기·학년·교과목·평가영역·학번으로 구분하며, 동일 기록은 중복 저장하지 않습니다. 변경된 점수는 확인 후 갱신합니다. 실제 반은 반/번호 열을 사용합니다. 미등록 점수와 0점은 구분합니다. 평균은 등록된 숫자 점수만 계산합니다. PDF의 학년 전체 평균과 등록된 자료 평균은 별개입니다. 브라우저 저장소는 파일 이동·브라우저 변경·데이터 삭제 시 유지되지 않을 수 있으므로 백업하세요. 스캔 PDF나 다른 양식은 지원하지 않을 수 있습니다.

현재 선택한 반의 등록된 전체 학생을 번호순으로 출력합니다. 수행평가 일괄등록 양식에는 정기시험·결시명칭·비고가 포함되지 않습니다.

성취도 목표점수에 반영하기

현재 선택한 학년도·학기·학년·교과목을 대상으로 반영합니다. 원점수와 만점을 유지합니다. 반영비율은 학교 평가계획에 따라 직접 입력하세요. 이후 연결된 평가·반의 점수는 통합관리가 변경될 때 자동 갱신됩니다.

기존 성취도 자료 처리 방법

실제 반영 전에는 기존 자료가 변경되지 않습니다. 전체 교체 시 성취도 기준은 유지합니다.

평가 영역 및 연결 대상

아직 응시하지 않은 평가

기말고사 등 앞으로 치를 평가의 이름·만점·반영비율을 추가하세요. 점수는 입력하지 않고 목표점수 계산에 사용합니다. 나중에 같은 종류와 이름의 성적 파일을 등록하면 같은 평가에 연결됩니다.

기존 성취도 평가 중 별도로 유지할 항목

위에서 연결되지 않은 기존 평가입니다. 반영비율을 수정하거나, 기존 점수까지 포함하여 해당 평가를 삭제할 수 있습니다. 삭제는 전체 학생에게 적용됩니다. 연결된 평가를 삭제하려면 위에서 해당 평가의 선택을 해제하세요.

반 선택

예정 평가의 점수는 빈칸으로 남기며 기존 점수를 덮어쓰지 않습니다. 원본 성적표의 빈칸은 연결된 점수를 비우고, 원본에 행이 없는 학생의 기존 점수는 유지합니다.
