📖 수행평가 일괄 평가 시스템 사용 가이드

⚙️ 1단계 : 평가 기준 세팅하기

상단의 [⚙️ 평가 영역 설정] 탭을 열어 출력물 제목, 영역명, 배점, 평가 방식을 설정하세요.
각 입력칸은 숫자를 치는 '숫자 입력형'과 마우스나 방향키로 고르는 '버튼 선택형'을 고를 수 있습니다.
※ 각 영역의 '🖨️ 기준표 포함' 및 '🖨️ 환산 근거 포함'을 체크/해제하여 출력 내용을 조절할 수 있습니다.

📋 2단계 : 학생 명단 붙여넣기 (4자리/5자리 자동 합치기 지원)

엑셀 파일에서 '학번, 이름' 또는 '학년, 반, 번호, 이름' 열을 복사하여 화면 중앙의 입력창(텍스트 영역)에 붙여넣고,
[📋 명단 불러오기] 버튼을 누르면 학년·반·번호가 자동으로 학번(4자리 또는 5자리)으로 합쳐져 채점용 표가 생성됩니다.

✍️ 3단계 : 폭풍 채점 (영역별 / 세부항목별 일괄 붙여넣기)

1) 직접 채점: 표에서 점수를 누르고 키보드 Tab, Enter, 방향키를 누르면 빠르게 다음 학생으로 넘어갑니다.
2) 영역별/항목별 엑셀 연동: 엑셀에 적어둔 여러 열의 점수들을 영역 제목 옆의 [📋 영역 일괄붙여넣기]로 한꺼번에 넣거나, 각 세부 항목 아래의 [📋 일괄붙여넣기]로 한 줄씩 채울 수 있습니다.
★ 입력하는 모든 내용은 실시간 자동 저장 되므로 창이 닫혀도 안심하세요.

🖨️ 4단계 : 피드백 인쇄 및 파일 관리

- 결과 통지: [🖨️ 인쇄]를 눌러 학생별 A4 1장 피드백을 인쇄하거나, [📝 텍스트 복사]로 알림장에 전송하세요.
- 다른 반 적용: 현재 반 채점이 끝났다면 [💾 전체 백업 저장]으로 보관한 뒤 명단을 지우고 다음 반을 시작하세요.
